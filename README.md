Пет-проект. Создан в учебных целях.

FutureTech — многостраничный новостной сайт, посвященный искусственному интеллекту.

✨ Возможности:
Многостраничная структура — 6 страниц с уникальным контентом

Полная адаптивность — mobile, tablet, desktop

SCSS-архитектура — переменные, миксины, модули

Локальные иконки и шрифты — без внешних CDN

🚀 Запуск проекта
1. Установить зависимости
bash
npm install
2. Запустить компиляцию SCSS
bash
npm run sass-watch
